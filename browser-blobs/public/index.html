iroh-blobs in the browser

This example runs iroh-blobs in the browser, compiled to WebAssembly. The example implements a very basic demo for iroh-blobs: You can retrieve a file that is served from the terminal app. It's not buffered in memory, so you can retrieve arbitrarily sized files.

Usage: Paste the ticket that was printed by the CLI tool that was run with cargo run /path/to/file.
